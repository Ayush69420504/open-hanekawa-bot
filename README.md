Note :- For all function refer to Functions.md, To develop refer to How_to_develop.md

How to run :-

    Barebones = Create a venv or not, i do not care. requirements.txt contains all libraries needed. Check the proper architecture for ffmpeg-static. defaults.json must be set with a ego, prefix and proper token be written to respective token file.
    Docker = Set the ego, prefix, auth_token for your bot. And buid the image. Size should be around 500-600 MB on disk. Port 6900 is to be exposed, no other requirements.

Note: The data available in data folder is free to use :)

Note: Hanekawa-san.service is a systemd service file that manages starting of discord bot on boot time

Note: Message replies are hard coded in a speech manner resembling Hanekawa Tsubasa san a side character in the monogatari series and light novels by nisio isin

Note: https://www.youtube.com/watch?v=QmMcE3SZZlY see this video to understand her character

My request: Watch the Monogatari series :) You can also read the light novels or the BakeMonogatari Manga. Its a very well written japanese style story, it is heavy on japanese refferences, but if you ignore them, it delves into philosophy using themes of monsters or abberations (Note:- Bake = Monster, Monogatari = Story). Basically the abberations are supposed to reflect mental or physical issues in a person or a world. I like the idea, the execution is very Nisio-Isin (the author).
